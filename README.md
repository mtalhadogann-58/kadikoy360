# Kadıköy360

Mobil öncelikli sandık koordinasyon, vaka takibi ve seçim tutanağı doğrulama uygulaması.

Vercel'de `OPENAI_API_KEY` ortam değişkenini ekleyin. Demo giriş: `admin` / `test123`.

Demo kullanıcı bilgileri üretimde kullanılmamalıdır. Gerçek kullanım için güvenli kimlik doğrulama, kalıcı veritabanı, dosya saklama ve denetim kayıtları eklenmelidir.
